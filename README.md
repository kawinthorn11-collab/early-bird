# Early Bird · เรียนล่วงหน้าเอกอังกฤษ

เว็บแอปช่วยเตรียมตัวเรียนสาขาวิชาภาษาอังกฤษ (หลักสูตรศิลปศาสตรบัณฑิต) คณะมนุษยศาสตร์และการจัดการการท่องเที่ยว มหาวิทยาลัยกรุงเทพ ก่อนเปิดเทอม ตั้งค่าเริ่มต้นไว้สำหรับรุ่น 1/1 แผนสหกิจศึกษา ภาคเรียนแรกเปิด 16 ส.ค. 2570

**ไม่ใช่เว็บไซต์ทางการของมหาวิทยาลัยกรุงเทพ** เนื้อหาเตรียมตัวเขียนจากคำอธิบายรายวิชาที่มหาวิทยาลัยเผยแพร่ เนื้อหาจริงในห้องขึ้นกับอาจารย์ผู้สอน และวันที่อาจเปลี่ยนตามประกาศของมหาวิทยาลัย

## ทำอะไรได้

- **วันนี้** ปุ่มเดียว เริ่ม Quick Run 2 นาที (โจทย์จากหน่วยที่เปิดแล้ว ข้อที่ผิดกลับมาตามรอบ 1, 3, 7, 16 วัน) นับถอยหลังถึงวันเปิดภาค บอกหน่วยที่ต้องเตรียมวันนี้ และแถบ 7 วัน
- **แผน 4 ปี** ทุกภาคตาม Year Plan 2570 พร้อมหน่วยกิต วิชาที่ต้องผ่านก่อน ความพร้อมเป็นเปอร์เซ็นต์ และช่องเลือกวิชาเลือก (Special Interest, Free Elective, Major Elective)
- **หน้าวิชา** คำอธิบายรายวิชาไทยและอังกฤษจากหลักสูตร สิ่งที่น่าจะเจอในห้อง และหน่วยเตรียมตัว (การ์ด ศัพท์พร้อมเสียง โจทย์ฝึก พูดออกเสียง งานเล็ก)
- **ปฏิทิน** วันสำคัญปีการศึกษา 2570 เรียงตามเวลา พร้อมบอกว่าอีกกี่วัน
- **ฝึกพูด** บันไดความกล้าและวงคุยในคลาสจำลอง สำหรับ EN101 และ ENL111
- **ตั้งค่า** รุ่น แผนการเรียน วันเปิดปิดภาค เสียง ธีม และ Export / Import

ตัวจัดตาราง (`src/schedule.ts`) กระจายหน่วยของวิชาภาคถัดไปให้เสร็จก่อนวันเปิดภาค วิชาภาค 1/1 และ 1/2 ต้องเสร็จก่อน 16 ส.ค. 2570 พอเปิดภาคแล้ว วิชาของภาคนั้นกลายเป็น "ทบทวน" และวิชาภาคถัดไปกลายเป็น "กำลังเตรียม"

ข้อมูลความคืบหน้าเก็บใน IndexedDB ของเบราว์เซอร์ (ฐานข้อมูลชื่อ `bu-english`) ไม่ส่งไปที่ไหน

## วิธีรัน

ต้องมี Node.js 22

```bash
npm install
npm run dev          # เปิด http://localhost:5190
npm test             # ทดสอบตัวแผน ตัวจัดตาราง Quick Run และการพูด
npm run validate     # ตรวจเนื้อหาทั้งหมด
npm run build        # สร้างเว็บแบบ static ไว้ที่ dist/
```

เว็บที่ build แล้วเป็น static ล้วน ไม่ต้องมีเซิร์ฟเวอร์ (`base: './'`) ใช้กับ GitHub Pages ได้ทันที ไฟล์ `.github/workflows/pages.yml` รันเทสต์แล้ว deploy เมื่อ push ขึ้น `main` (เปิด Pages แบบ GitHub Actions ในตั้งค่าของ repo ก่อน) ตอนรัน `npm run dev` ในเครื่อง มี `/api` เสริมสำหรับถอดเสียงพูดและ AI ผ่าน `server/api.mjs` แต่เว็บออนไลน์ไม่ใช้

## เพิ่มเนื้อหาของวิชา

1. สร้าง `content/courses/<CODE>.json` เช่น `content/courses/EN103.json` ตามรูปแบบใน `content/COURSE_SCHEMA.md` (หน่วยละ การ์ด 3 ถึง 5 ใบ ศัพท์ 5 ถึง 10 คู่ โจทย์อย่างน้อย 8 ข้อพร้อมเหตุผลทุกตัวเลือก ประโยคพูด 2 ถึง 3 ประโยค และงานเล็ก 1 อย่าง)
2. ใช้บทไวยากรณ์เดิมซ้ำได้ด้วย `"lessons": ["L01"]` และคำถามฝึกพูดด้วย `"interview": ["I01"]`
3. รัน `node scripts/check-courses.mjs` แล้ว `npm run validate`
4. ไม่ต้องแก้โค้ด หน้าวิชา แผน 4 ปี ตัวจัดตาราง และ Quick Run อ่านไฟล์ใหม่เอง วิชาที่ยังไม่มีไฟล์จะแสดงคำอธิบายรายวิชาพร้อมข้อความ "เนื้อหาเตรียมตัวกำลังมา"

ถ้าแก้ `source/curriculum-extract.md` ให้รัน `npm run catalog` เพื่อสร้าง `content/catalog.json` ใหม่ (`npm run validate` จะฟ้องถ้าสองไฟล์ไม่ตรงกัน) ไอคอนแอปสร้างด้วย `npm run icons`
